# Trained Models

This directory represents the trained models produced during the Surface Defect Detection project.

The project evaluates three main deep-learning architectures:

1. Baseline CNN
2. MobileNetV2
3. ResNet18

MobileNetV2 was evaluated using both frozen-feature and fine-tuned training strategies.

## Generated Models

The experiments generate trained model weights for:

- Baseline CNN
- Frozen MobileNetV2
- Fine-Tuned MobileNetV2
- ResNet18

The trained model files are stored externally in the project's Google Drive workspace because model weight files can be large and are therefore not included directly in the GitHub repository.

## Model Training

The models are generated by the following notebooks:

- `notebooks/02_baseline_cnn.ipynb`
- `notebooks/03_mobilenetv2.ipynb`
- `notebooks/04_resnet18.ipynb`

All models use the same train, validation, and test split generated by:

`notebooks/01_dataset_preparation.ipynb`

## Model Evaluation

The models are evaluated using:

- Accuracy
- Macro Precision
- Macro Recall
- Macro F1-Score
- Confusion Matrix
- Training and validation performance

The final comparison between the models is performed in:

`notebooks/05_final_evaluation.ipynb`

## Reproducibility

The trained models can be regenerated by running the corresponding training notebooks using the dataset split described in `data/README.md`.
